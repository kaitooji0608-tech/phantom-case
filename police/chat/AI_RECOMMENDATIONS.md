# SECURE CHAT — AIレコメンド / 自由入力判定一覧

この表は `police/assets/js/chat.js` の会話フェーズと対応しています。

## 基本仕様

- AIレコメンド表示中に自由入力しても、**正しい意図として判定されるまではレコメンドを消さない**。
- ボタン文言と完全一致しなくても、同じ意味の自由入力なら次へ進む。
- 関係ない入力の場合は相沢がそのフェーズ用の返答を行い、同じレコメンドを残す。
- 判定は会話フェーズごとに分離する。同じ言葉でも、別フェーズでは勝手に進まない。

| フェーズ | AIレコメンド | 前に進む自由入力例 | 関係ない入力時 |
|---|---|---|---|
| `offer` | 「捜査に協力する」 / 「捜査に協力しない」 | 協力します、やります、手伝います、はい / 協力しません、無理、嫌です、断ります | 質問を再表示し、レコメンド維持 |
| `mission` | なし | GLITCH、glitch、グリッチ、GLITCHと出ました | 通常応答 |
| `askSquirrelQR` | 「リスの置物の下から、QRコードを見つけました」 | リスの下にQRがありました、QRを見つけた、二次元コードを発見した | 心当たり確認を返し、レコメンド維持 |
| `askSquirrelWhere` | 「私の家です」 | 家です、自宅です、うちです、自分の家にあります | 場所を再確認し、レコメンド維持 |
| `askSquirrelExisting` | 「はい」 | はい、うん、以前から、前からありました、元々ありました | 以前からあったか再確認し、レコメンド維持 |
| `afterTakeover` | 「怪しい人物と会話しました」 | 怪しい人と話した、誰かと会話した、UNKNOWNが出た、怪盗みたいな人が出た、メッセージが来た | 「その間、何かありましたか？」を返し、レコメンド維持 |
| `askStolenItem` | 「今のところ分かりません」 | わかりません、わからん、不明です、心当たりない、まだ分からない | 盗難の心当たりを再確認し、レコメンド維持 |
| `askHomeAbnormality` | 「今のところ特にありません」 | 特にない、何もない、異常なし、変わったことはない、大丈夫です | 家の異常を再確認し、レコメンド維持 |
| `askContinuePhase2` | 「分かりました。確認してみます」 | わかりました、了解、確認します、見てみます、調べます、やってみます、はい | 確認をお願いする返答＋レコメンド維持 |
| `phase2` | なし | 謎が全部解けました、全部解けた、解き終わりました、クリアしました | 調査継続中の返答 |
| `finalAskStolen` | 「特にありませんでした」 | 特にない、何もない、ありませんでした、盗まれてない、盗られてない | 盗難有無を再確認し、レコメンド維持 |

## 本人確認

- 日付正解：`2022/10/2`、`2022年10月2日`、`10/2` など。
- `10/3` は専用ヒントを返す。
- 場所正解：`愛媛`、`松山`、`道後` を含む入力。

## 実装上の注意

自由入力を送った直後に `clearActions()` しないこと。
正しいIntentが成立して遷移関数へ入った時点でのみ、レコメンドを消す。
