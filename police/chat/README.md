## 仮URL

`script.js` 冒頭：

```js
puzzleUrl: "../../mystery/",
databaseUrl: "../db/",
```

謎ページの正式なパスが決まったら変更してください。

## テスト時のリセット

画面にはリセットボタンを出していません。
開発中だけURL末尾に `?reset=1` を付ければ履歴を消せます。

例：

```text
https://phantom-case-police.github.io/phantom-case/police/chat/?reset=1
```
