被害者の誕生日を翌日に控えた2022年10月2日、誕生日プレゼントが何者かによって持ち去られた。現場には複数の暗号および謎が残されており、被害者がそれらを順次解読した結果、プレゼントは無事に回収された。一連の手口および残されたメッセージから、通称「怪盗ヘンタイおじさん」による犯行と判断されている。

被疑者情報

怪盗ヘンタイおじさん
通称 / K.H.O. / 現在逃走中
  • 犯行現場に謎解き・暗号・メッセージを残す特徴がある。
  • 金銭的利益を目的とした一般的な窃盗犯とは行動傾向が異なる。
  • CASE 01では、最終的に被害品を被害者自身が回収できるよう誘導していた。
  • 捜査班では「誕生日を祝うこと自体が犯行目的の一部であった可能性」を指摘している。
  • 中目黒周辺のキャバクラに頻繁に出入りしているとの情報あり。捜査上の重要性は不明。

事件経過

2022.10.02

誕生日プレゼントの消失を確認。現場に怪盗ヘンタイおじさんによるものとみられるメッセージが残される。

同日

被害者が犯人の残した複数の謎を解読。プレゼントの所在につながる情報を順次取得。

同日

被害者がプレゼントを回収。人的被害なし。

以降

怪盗ヘンタイおじさんの身柄確保には至らず。関連情報の収集を継続。

主な証拠・特徴

E-01 / 犯行メッセージ被害者に対し、謎を解くよう要求する内容。
E-02 / 複数の暗号被害者本人の知識や記憶を利用した問題が含まれていた。
E-03 / 誕生日プレゼント最終的に被害者が回収。破損等は確認されていない。
E-04 / 犯行動機祝福目的の可能性。通常の窃盗事件とは異なる。

担当捜査官メモ

本件は形式上「盗難事件」であるものの、被疑者は被害品の換金・処分を目的としていなかった可能性が高い。被害者に謎を解かせ、最終的に誕生日プレゼントへ到達させること自体が一連の犯行計画に含まれていたとみられる。

被疑者の行動は極めて迷惑ではあるが、被害者の誕生日を祝おうとしていた形跡も認められる。
