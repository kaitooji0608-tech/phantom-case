# Phantom Case Flow v4

全体フロー確認用の実装です。

今回の重要な変更：
**別ページから警察チャットへ戻っても、会話は自動では開始しません。**
各ページでは「解いた・見つけた」という事実だけを保存し、
チャットへ戻ったあとにユーザー自身が「相沢に報告する」を押して初めて会話が進みます。

## 全体フロー

### 1. 警察チャット
`/police/chat/`

- SECURE CHAT開始
- 本人確認
  - 日付：2022/10/02
  - 場所：愛媛 / 松山 / 道後
- 捜査協力
- 「協力しない」は2回まで
- 謎ページ・DBを共有

### 2. 警察の闇3問
`/mystery/`

テスト回答：
- OP-GOLD
- G-404
- MF-POST

3つ解くと、
「警察チャットに戻る」だけが表示されます。

### 3. チャットへ戻る
元の会話履歴がそのまま表示され、
「相沢に報告する」ボタンが出ます。

押すと：
- 自分「謎が解けました」
- 相沢が内容確認
- 自分が3件を共有
- 相沢「本当？」
- 怪盗ヘンタイおじさん乱入
- 新しい家謎を解放
- 相沢復帰

### 4. 最初の家謎
`/house/`

答え：リス

正解すると、実際のリスの置物を探すよう促します。

### 5. リス用QR
`/house/squirrel/`

ここでは
「リスのQRを見つけた」
という事実だけ保存します。

画面には：
「相沢クンにも教えてあげよう」
「警察チャットに戻る」

### 6. チャットへ戻る
また元の履歴が表示され、
「相沢に報告する」ボタンが出ます。

押すと：
- 自分「QRコードを見つけました」
- 相沢「どこに？」
- 自分「家のリスの置物」
- 相沢「元から？」
- 自分「いいえ」
- 相沢「侵入された可能性があります」
- 残り3つの痕跡捜索を依頼

### 7. 家QR 3つ
- `/house/trace1/` → 答え「あお」
- `/house/trace2/` → 答え「2」
- `/house/trace3/` → 答え「かぎ」

3つ全部見つけるとエンディング解放。

### 8. ENDING
`/ending/`

最後の問題：
「今回、この家から何を盗んだ？」

答え例：
- 何も盗んでいない
- なにも
- 何も

正解すると、
「実は驚かせたかっただけ」
「誕生日おめでとう」
まで表示します。

## v4.1 修正
チャットの状態遷移を修正しました。

- 「謎が解けました」送信後：
  - 相沢「3つともですか？」
  - 相沢「どんな内容だったか教えてもらえますか？」
  - ［3件の内容を共有する］
  - その後、怪盗乱入へ進みます。
- リスQR報告後：
  - 相沢「どこにあった？」
  - ［家にあるリスの置物についていました］
  - 相沢「元から？」
  - ［もともとは付いていません］
  - 侵入疑惑へ進みます。

原因は、汎用の「未報告なら相沢に報告する」判定が
会話途中のフェーズより先に評価されていたことでした。
v4.1では会話途中のフェーズを最優先にしています。


# v5 修正

## 無限ループ対策
「相沢に報告する」を押した瞬間にチャットの内部フェーズを
`dark-summary` へ変更してから会話を表示するようにしました。

そのため、

1. ［相沢に報告する］
2. 自分「謎が解けました」
3. 相沢「3つともですか？」
4. 相沢「どんな内容だったか教えてもらえますか？」
5. ［3件の内容を共有する］

となり、［相沢に報告する］へ戻りません。

同様にリスQR報告も、
ボタンを押した瞬間に次フェーズへ固定しています。

## 謎ページと警察DBの共有方法

従来の「出所不明Webページを開く」「参考資料DBを開く」という
チャット下部のボタンは削除しました。
