# Phantom Case Flow v2

全体ストーリーとページ遷移の確認用プロトタイプです。
細かい台詞・本物のARG・本物の家謎は後で差し替える前提です。

## 全体フロー

1. `/police/chat/`
   - SECURE CHAT開始画面
   - 本人確認
   - 日付：2022/10/02
   - 場所：愛媛 / 松山 / 道後
   - 捜査協力

2. `/mystery/`
   - 警察DBの闇3つのKEYを入力
   - テスト回答：
     - OP-GOLD
     - G-404
     - MF-POST

3. `/police/chat/`
   - 3件を相沢に報告
   - 相沢「本当？」
   - 怪盗ヘンタイおじさん乱入
   - 新しい家謎を解放
   - 相沢復帰

4. `/house/`
   - 最初の家謎
   - 答え：リス
   - 実際のリスの置物を探す

5. `/house/squirrel/`
   - リスの置物に付けるQR
   - TRACE 00 FOUND
   - 「相沢クンにも教えてあげよう」
   - 警察チャットへ

6. `/police/chat/`
   - 相沢「どうやって見つけた？」
   - 「家のリスの置物」
   - 「元から付いていた？」
   - 「いいえ」
   - 自宅侵入の可能性を認識
   - 残り3痕跡の捜索を依頼

7. `/house/trace1/` ～ `/house/trace3/`
   - 家のQR3枚
   - 仮問題
   - すべてFOUNDでEND解放

8. `/ending/`
   - 仮END
   - 本番では「何を盗んだ？」→「何も盗んでいない」→誕生日サプライズ

## テスト回答

- 闇①：OP-GOLD
- 闇②：G-404
- 闇③：MF-POST
- 最初の家謎：リス
- TRACE01：あお
- TRACE02：2
- TRACE03：かぎ

## テスト用QR
`/house/qr-print/`

リス用QR 1枚 + 残りの痕跡用QR 3枚を表示します。

## 全リセット
警察チャットURLに `?reset=1` を付けてください。

例：
`/police/chat/?reset=1`

進行状況は1つの localStorage キー
`phantom_case_master_state_v2`
で一元管理しています。


## v3 修正
- 謎3問クリア後の「相沢に報告」で、SECURE CHAT開始画面を出さず元のチャット履歴へ直接戻ります。
- 戻った直後に「3つの記録を確認しました」から会話が自動で続きます。
- リスQRから「相沢に報告」した場合も同様に、元チャットへ直接戻って会話を継続します。
- CSS/JSに `?v=3` を付け、GitHub Pages / ブラウザの古いキャッシュを避けています。
