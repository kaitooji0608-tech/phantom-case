# Phantom Case Flow v6

今回の変更は2点です。

## 1. 回答欄に明確なボタンを追加
スマホでEnterを押さなくても進められるよう、回答入力のある画面すべてにボタンを付けました。

- 警察の闇3問：［回答する］
- 最初の家謎「リス」：［回答する］
- 残り3つの謎：［回答する］
- 残り3つのキーワード：［キーワードを確認］
- 最終問題：［回答する］

Enterでも従来どおり送信できます。

## 2. 残り3つの痕跡をQR方式から変更

リスだけは特別なQRとして残します。

その後の3つは、各TRACEごとに次の流れです。

1. Web上の謎を解く
2. 答えによって家の中の「場所」が判明
3. 実際にその場所へ行く
4. 置いてある現物カードを見つける
5. カードに書かれたキーワードをWebへ入力
6. TRACE FOUND

これにより「QRラリー」ではなく、家の中を実際に捜査している感覚を出します。
